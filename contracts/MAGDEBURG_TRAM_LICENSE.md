# Magdeburg tram reference alignments

`magdeburg-tram-lines.json` contains OpenStreetMap route relations and tram
track ways, downloaded through Overpass. OSM base/retrieval times and exact
query are embedded. © OpenStreetMap contributors, ODbL 1.0:
https://www.openstreetmap.org/copyright

These are mapped reference alignments, not measured vehicle trajectories or
certified GTFS service shapes. Android retains visible OSM attribution.

Reproduce with `python validation/fetch_magdeburg_tram_lines.py`.
