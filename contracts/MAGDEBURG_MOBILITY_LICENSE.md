# Magdeburg mobility snapshot

© OpenStreetMap contributors, licensed under the Open Database License 1.0.

Source: OpenStreetMap through https://overpass-api.de/api/interpreter.
The exact query, retrieval timestamp and OSM base timestamp are retained in
`magdeburg-mobility.json`. This database extract contains mapped parking,
parking entrances and public transport stop/platform elements for Magdeburg.
It is not live parking occupancy or an assurance of public access.
